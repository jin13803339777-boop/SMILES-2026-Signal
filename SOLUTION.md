## 1. Problem understanding

The task is to recover a cleaner four-channel complex received signal from a physical device that simultaneously transmits and receives signals. The observed signal can be written as

```text
rx[n, c] = s[n, c] + I[n, c] + noise[n, c],
```

where `s` is the desired signal, and `I` is the interference to be removed. The challenge statement specifies two major interference mechanisms:

1. **TX-driven nonlinear interference.** This component is generated by the six transmitted complex channels. It can include nonlinear cross-products between different TX channels.
2. **External spatially coherent interference.** This component is not a function of `tx`, but it appears across all four RX channels with different complex amplitudes and phases. This suggests a low-rank, especially rank-1, spatial structure.

The official score is computed only in a narrow frequency band where the interference is concentrated. A valid removed component must be explainable mainly as the sum of a TX-driven nonlinear part and a spatially coherent rank-1 residual. Therefore, I chose an interpretable signal-processing approach rather than a black-box neural model.

---

## 2. Final method

My final solution is a two-stage canceller:

```text
rx_hat = rx - I_tx - I_rank1,
```

where `I_tx` is a nonlinear TX-driven prediction and `I_rank1` is a spatially coherent residual component.

### 2.1 Stage 1: nonlinear TX-driven least-squares cancellation

The official baseline already provides a well-designed nonlinear basis built from TX cross-products and short time lags. I preserve this fixed task logic and use the helper function `fit_tx_prediction` to estimate the TX-driven component.

Conceptually, for each receive channel, the band-limited interference is approximated by a complex linear combination of nonlinear TX features:

```text
I_tx[:, c] ≈ Σ_j Σ_lag a[j, lag, c] · phi_j(tx shifted by lag),
```

where the `phi_j` terms include cross-products such as `tx_i^2 * conj(tx_k)`. The coefficients are estimated by complex least squares on the official modeling window.

This stage is mathematically aligned with my background in linear algebra, least-squares approximation, and signal modeling: instead of training a neural network, it builds a structured feature space and projects the observed band-limited interference onto that space.

### 2.2 Stage 2: rank-1 spatial residual cancellation

After the TX-driven component is removed, the residual may still contain the external coherent source. I estimate it from the band-limited residual matrix:

```text
B = bandpass(rx - I_tx),          B in C^(N x 4).
```

Since the external interference is shared across RX channels with different amplitudes and phases, I model it as a rank-1 matrix:

```text
B_rank1 = u v*,
```

where `u` is a shared complex temporal waveform and `v` contains the complex channel gains. In implementation, this is obtained by the top eigenvector of the four-by-four channel covariance matrix

```text
C = B^H B / N.
```

This is a principal-component/SVD-style step. It is simple, reproducible, and directly follows the spatial-coherence assumption in the problem statement.

### 2.3 Gain correction and conservative shrinkage

The official metric applies the scoring bandpass internally. Because my rank-1 residual is already estimated in the band-limited domain, I fit a small complex gain per channel after accounting for the additional scoring filter. I also cap the gain magnitude to avoid numerical over-correction.

Finally, I test a small set of conservative shrinkage values:

```text
0.50, 0.70, 0.85, 1.00
```

The candidate with the best public scorer value is selected. This is not a change to the official task file; it is a safety mechanism inside the applicant code to avoid returning an invalid over-subtracted signal.

## 6. Experiments and failed attempts

### 6.1 TX-only baseline

The official baseline is a strong starting point because it uses nonlinear TX cross-products and time lags. However, it does not explicitly model the external coherent interference. This motivated the second rank-1 residual stage.

### 6.2 Full-rank residual subtraction

A natural idea is to subtract the entire band-limited post-TX residual. I discarded this because it can remove desired signal energy and may fail the explainability requirement. The task specifically expects the removed component to be mostly TX-driven plus rank-1 coherent, not arbitrary full-rank residual energy.

### 6.3 Independent per-channel residual cancellation

Another attempt is to estimate a separate residual for each RX channel. I discarded this because it ignores spatial coherence. It can improve a channel-wise power metric locally but is less consistent with the physical structure of the external source.

### 6.4 Black-box neural network

A neural network could be trained to map `tx` to `rx`, but it would require careful validation, additional hyperparameter choices, and a risk of poor interpretability. Since the challenge provides a clear structural model and a short capture, a low-rank signal-processing solution is more appropriate.

---

## 7. Limitations

1. The rank-1 residual stage assumes that the dominant post-TX residual in the scoring band is external coherent interference. If the desired signal is also strongly rank-1 in the same band, the method may remove part of it.
2. The gain correction is conservative. This improves robustness but may leave some removable interference.
3. The approach is designed for the provided scoring structure and capture. For a larger benchmark, I would validate the shrinkage policy across multiple captures.

---

## 8. Conclusion

My solution combines structured nonlinear least squares with low-rank complex linear algebra. The method is transparent, reproducible, and aligned with the stated physics of the task: a TX-driven nonlinear component plus a spatially coherent external component. It also reflects my mathematical training: projection, approximation, covariance analysis, and careful model selection under constraints.

# Appendix: Chinese translation / 中文翻译

## 1. 问题理解

本任务要求从一个物理设备的四通道复数接收信号中恢复更干净的接收信号。该设备同时发射和接收信号，因此接收信号会被自身发射信号泄漏产生的结构化干扰污染。观测信号可以理解为：

```text
rx[n, c] = s[n, c] + I[n, c] + noise[n, c]
```

其中 `s` 是希望保留的真实信号，`I` 是需要去除的干扰。题目说明干扰主要由两部分组成：

1. **由 TX 驱动的非线性干扰。** 这部分由六个发射通道产生，可能包含不同 TX 通道之间的非线性交叉项。
2. **外部空间相干干扰。** 这部分不是 `tx` 的函数，但会以不同的复幅度和相位出现在四个 RX 通道中，因此具有低秩、尤其是秩一结构。

官方评分只在干扰集中的窄频带内计算。有效的去除成分必须主要能够解释为“TX 驱动的非线性部分 + 空间相干的秩一残差”。因此，我选择了可解释的信号处理方法，而不是黑箱神经网络。

## 2. 最终方法

最终方法是两阶段抵消器：

```text
rx_hat = rx - I_tx - I_rank1
```

其中 `I_tx` 是由 TX 预测出的非线性干扰，`I_rank1` 是空间相干的秩一残差。

### 2.1 第一阶段：TX 驱动的非线性最小二乘抵消

官方基线已经提供了一个设计合理的非线性 TX 特征空间，其中包括 TX 交叉项和短时间滞后。我保留固定任务逻辑，使用 `fit_tx_prediction` 估计 TX 驱动干扰。

从数学上看，每个接收通道的带限干扰可以近似为非线性 TX 特征的复线性组合：

```text
I_tx[:, c] ≈ Σ_j Σ_lag a[j, lag, c] · phi_j(tx shifted by lag)
```

其中 `phi_j` 包含类似 `tx_i^2 * conj(tx_k)` 的交叉项。系数通过复数最小二乘估计得到。

这一阶段与我的线性代数、最小二乘近似和建模训练相吻合：它不是训练黑箱模型，而是在结构化特征空间中进行投影和逼近。

### 2.2 第二阶段：秩一空间残差抵消

去除 TX 驱动干扰后，残差中仍可能包含外部相干干扰。我先对残差信号进行评分频带滤波，得到矩阵：

```text
B = bandpass(rx - I_tx),          B in C^(N x 4)
```

由于外部干扰会以不同复幅度和相位出现在四个 RX 通道中，我将其建模为秩一矩阵：

```text
B_rank1 = u v*
```

其中 `u` 是共享的复数时间波形，`v` 是四个通道上的复数增益。实现时，我使用四通道协方差矩阵

```text
C = B^H B / N
```

的最大特征向量来估计该成分。这相当于一个主成分分析或 SVD 风格的步骤，简单、可复现，也直接对应题目中的空间相干假设。

### 2.3 增益校正与保守收缩

官方指标会在内部再次应用评分频带滤波。由于秩一残差已经是在带限域中估计得到的，我进一步对每个通道拟合一个小的复数增益，以补偿这次额外滤波。同时，我限制增益幅度，避免数值上的过度抵消。

最后，我测试一组保守的收缩系数：

```text
0.50, 0.70, 0.85, 1.00
```

选择公共评分器下表现最好的候选结果。这并没有修改官方任务文件，而是在申请者代码内部增加的安全机制，用于避免返回无效的过度抵消结果。

## 6. 实验与舍弃方案

### 6.1 仅使用 TX baseline

官方 baseline 是很强的起点，因为它使用了 TX 非线性交叉项和时间滞后。但它没有显式建模外部相干干扰，因此我加入了第二阶段的秩一残差抵消。

### 6.2 全秩残差抵消

一个直接想法是把 TX 抵消后的全部带限残差都减掉。但这种方法可能移除真实信号，并且可能无法通过官方的可解释性检查。题目要求移除成分主要是 TX 驱动部分和秩一相干部分，而不是任意全秩残差。

### 6.3 各通道独立残差抵消

另一种方法是对每个 RX 通道单独估计残差。但这忽略了外部干扰的空间相干结构，可能提升局部功率指标，却不符合问题的物理结构。

### 6.4 黑箱神经网络

可以训练神经网络从 `tx` 映射到 `rx`，但这会引入额外超参数、验证困难和可解释性风险。由于题目已经给出清晰的结构假设，低秩信号处理方法更加合适。

## 7. 局限性

1. 秩一残差阶段假设 TX 抵消后的主导带限残差是外部相干干扰。如果真实信号本身也在同一频带中呈现强秩一结构，方法可能会移除部分真实信号。
2. 增益校正较为保守，因此可能保留一部分可去除干扰。
3. 该方法针对当前评分结构和数据捕获设计。如果有更大的数据集，我会在多个捕获上验证收缩策略。

## 8. 总结

我的方案结合了结构化非线性最小二乘和低秩复线性代数。它透明、可复现，并与题目中的物理假设一致：干扰由 TX 驱动的非线性部分和空间相干的外部部分组成。该方法也体现了我的数学训练，包括投影、逼近、协方差分析和约束下的模型选择。
