# SMILES-2026 Signal Interference Cancellation

This repository contains my application project solution for **SMILES-2026 Summer School of Machine Learning by Skoltech**.

The task is to cancel structured interference from complex multi-channel received signals. The received signal contains two removable parts:

1. a nonlinear TX-driven component generated by transmitted channels, and
2. a spatially coherent external component shared across four RX channels.

My final method keeps `task_and_baseline.py` unchanged and implements the applicant method in `applicant_solution.py`.

## Environment

Python 3.10+ is recommended.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## How to run

From the repository root:

```bash
python applicant_solution.py
```

The script will:

1. download `challenge.mat` if it is not already present;
2. load `tx`, `rx`, `Fs`, and `FC_TX`;
3. run the official TX-only baseline;
4. run my two-stage canceller;
5. write `results.json`.

After `results.json` is generated, optionally update the result table in `SOLUTION.md`:

```bash
python scripts/update_solution_results.py
```

## Final method

The solution combines:

- nonlinear least-squares prediction of the TX-driven interference; and
- rank-1 principal-component cancellation of the spatially coherent residual.

This design is intentionally mathematical and interpretable: it uses complex-valued linear algebra, band-limited least squares, and low-rank approximation rather than a black-box neural network.

## Reproducibility note

The dataset is ignored by git because it is large. A clean checkout remains runnable because `applicant_solution.py` downloads the dataset automatically using `gdown`. If automatic download fails, manually place `challenge.mat` in the repository root and rerun the command.
